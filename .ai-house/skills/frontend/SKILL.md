# Frontend Engineering

- Follow the framework, routing, state management, and component conventions already present.
- Keep components focused; avoid premature abstraction and unnecessary dependencies.
- Handle loading, empty, success, and error states; prevent duplicate submissions where relevant.
- Validate user input for usability, while never relying on client-side validation as the security boundary.
- Keep secrets and privileged logic out of client bundles.
- Check accessibility, responsive behavior, console errors, and avoid unnecessary re-renders when relevant.
- Use the repository's existing lint, type-check, test, and build commands.
