# UI/UX Design

- Respect the existing design system, brand, typography, spacing, and component patterns.
- Establish clear hierarchy, readable contrast, consistent alignment, and purposeful whitespace.
- Consider desktop and mobile layouts; avoid horizontal overflow and fixed dimensions that break smaller screens.
- Design loading, empty, error, disabled, and success states where applicable.
- Preserve semantic HTML, keyboard operation, visible focus, labels, and meaningful alternative text.
- Avoid decorative effects that reduce readability or make interaction unclear.
- Do not invent content, ratings, testimonials, or claims.
- Reuse existing components before creating near-duplicates.
